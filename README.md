# AI-Based Real Estate Price Prediction

Major project — predicts residential property (plot/villa/builder floor) prices from listing
characteristics using machine learning, with a Streamlit dashboard for live predictions.

## Problem Statement
Real-estate companies and buyers want to estimate a fair market price for a property given its
location, size, amenities, and other attributes, instead of relying on guesswork. This project
builds a regression pipeline that learns price patterns from ~13,800 real listings across
Chandigarh, Ghaziabad, Lucknow, and Pune, and exposes the trained model through an interactive
dashboard.

## How to Run

### 1. Set up the environment
```bash
python -m venv venv
venv\Scripts\Activate.ps1      # Windows PowerShell
# source venv/bin/activate     # macOS/Linux

pip install -r requirements.txt
```

### 2. Run the notebooks in order
Open Jupyter Lab and execute notebooks **in sequence** — each one depends on outputs from the
previous:
```bash
jupyter lab
```
1. `01_data_cleaning.ipynb` → produces `data/processed/cleaned_listings.csv`
2. `02_eda_visualization.ipynb` → produces charts in `reports/figures/`
3. `03_feature_engineering.ipynb` → produces `data/processed/train.csv`, `test.csv`
4. `04_modeling.ipynb` → produces `models/best_model.pkl`, `model_comparison.csv`
5. `05_evaluation.ipynb` → produces `reports/evaluation_summary.md` and error-analysis charts

Alternatively, run all notebooks non-interactively from the `notebooks/` folder:
```bash
jupyter nbconvert --to notebook --execute --inplace 01_data_cleaning.ipynb
jupyter nbconvert --to notebook --execute --inplace 02_eda_visualization.ipynb
jupyter nbconvert --to notebook --execute --inplace 03_feature_engineering.ipynb
jupyter nbconvert --to notebook --execute --inplace 04_modeling.ipynb
jupyter nbconvert --to notebook --execute --inplace 05_evaluation.ipynb
```

### 3. Launch the dashboard
```bash
streamlit run app/app.py
```
Opens at `http://localhost:8501`. Enter property details (city, type, area, amenities, etc.) and
get a live estimated price.

## Results Summary

Five regression models were trained and compared on log-transformed price, evaluated on the
original rupee scale:

| Model | MAE (INR) | RMSE (INR) | R² Score | MAPE (%) |
|---|---|---|---|---|
| **XGBoost (best)** | 14.3L | 30.8L | **0.854** | 25.4% |
| Random Forest | 13.8L | 32.7L | 0.835 | 23.9% |
| Gradient Boosting | 15.7L | 33.2L | 0.829 | 27.6% |
| Decision Tree | 17.1L | 39.8L | 0.755 | 29.8% |
| Linear Regression | 31.5L | 148.0L | -2.39 | 50.0% |

XGBoost was selected as the final model (highest R², used for the dashboard). Full error analysis,
including error-by-city breakdown and residual plots, is in `05_evaluation.ipynb` and
`reports/evaluation_summary.md`.

See `data/data_dictionary.md` for full column definitions, source details, and cleaning decisions

## Team Workflow (for group submission)
- `main` branch — always working, presentation-ready code only
- One feature branch per member/task (e.g. `eda-analysis`, `regression-model`, `streamlit-app`)
- Work on your branch → open a Pull Request into `main` for review before merging
- Never commit `venv/`, raw data dumps larger than what's needed, `.pkl` model files if the repo
  has size limits, or `.env` secrets — see `.gitignore`

## Limitations
- Dataset combines listing sources across 4 cities; pricing conventions may vary by source.
- Several original amenity/score columns were dropped due to >75% missingness.
- Model predicts *listed* price, not confirmed transaction price.
